# Otzaria Timeline

תוסף Timeline מקומי לאוצריא, בהשראת Windows Timeline.

## גרסה 0.4.0

- תמיכה ב־**Otzaria 0.9.97 ומעלה**.
- תצוגת יום כציר זמן חזותי אמיתי: קו אנכי, נקודות זמן, שעות וכרטיסי פעילות משני הצדדים.
- במסכים צרים הציר מתקפל לעמודה אחת כדי להישאר קריא.
- תצוגות שבוע וחודש נשארות כתצוגות כרטיסים מסכמות.
- ציר זמן לפי Sessions.
- כרטיסי Session עם Preview של הפעילות האחרונה.
- Snapshot אוטומטי בערך כל 15 דקות ובמעבר שולחן עבודה.
- Snapshot ידני.
- גלריית Snapshots אחרונים.
- בחירת Snapshot מדויק מתוך Session.
- "המשך מהמקום שבו הפסקת".
- שחזור מבוקר של טאבי ספרים ומיקומי הקריאה.
- מעבר לשולחן העבודה המקורי אם הוא עדיין קיים.
- Heatmap של 35 הימים האחרונים.
- חיפושים אחרונים מתוך היסטוריית אוצריא.
- איחוד אירועי קריאה רציפים כדי למנוע הצפה.
- חיפוש וסינון לפי סוג פעילות וטווח זמן.
- 100% מקומי, ללא רשת.

## תאימות 0.9.97

ה־manifest מצהיר כעת:

`"minAppVersion": "0.9.97"`

ה־CI כולל בדיקה ייעודית שנכשלת אם אחד הקבצים משתמש ב־API ידוע שנוסף רק ב־0.9.98.

ה־APIs המרכזיים של התוסף — כולל `workspace.list`, `workspace.getActive`, `workspace.switch`, `reader.closeTab`, `history.listSearches` ומעקב מיקום הקריאה — זמינים ב־0.9.97 או קודם.

## אריזה

בכל push לענף `main`, GitHub Actions:

1. בודק את `manifest.json`.
2. מוודא ש־`minAppVersion` נשאר 0.9.97.
3. בודק תחביר JavaScript.
4. בודק שלא נוספו APIs ידועים של 0.9.98.
5. אורז את התוסף לקובץ גרסה, לדוגמה:
   `timeline-plugin-0.4.0.otzplugin`
6. בודק שה־ZIP תקין.
7. מעלה אותו כ־Artifact.

קובץ `.otzplugin` הוא חבילת התוסף להתקנה באוצריא.

## מגבלת שחזור

ה־SDK אינו חושף מספיק מידע כדי לשחזר היסטורית כל סוג טאב של כלי, תוסף או חיפוש. לכן התוסף משחזר רק פריטים שיש דרך אמינה לבנות מחדש.

## פרטיות

כל הנתונים נשמרים ב־`plugin.storage` הפרטי של התוסף ואין שימוש ברשת.
