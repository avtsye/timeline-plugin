# Otzaria Timeline

תוסף Timeline מקומי לאוצריא, בהשראת Windows Timeline.

## גרסה 0.5.0

- תמיכה ב־**Otzaria 0.9.97 ומעלה**.
- תצוגת יום כציר זמן חזותי: קו אנכי, נקודות זמן וכרטיסי Session משני הצדדים.
- תצוגות שבוע וחודש ככרטיסי סיכום.
- מעקב אחר ספרים, מיקומי קריאה, ניווט, שולחנות עבודה, **תוספים וכלים מובנים**.
- מנוע רקע קל בודק את רשימת הטאבים הפתוחים כל 5 שניות ורושם רק תוסף/כלי חדש שנפתח אחרי ה־baseline הראשוני.
- כותרות Session חכמות לפי הספרים, התוספים והכלים שהיו פעילים.
- הצמדת Sessions חשובים.
- קיפול/פתיחה של Sessions.
- סימוני Snapshot על ציר הזמן.
- Snapshot אוטומטי, Snapshot ידני וגלריית Snapshots.
- שחזור מבוקר של ספרים ומיקומים.
- Heatmap, חיפוש וסינון.
- **התראות פנימיות של אוצריא** לאחר שמירת Snapshot, שחזור, השהיית/חידוש תיעוד, ניקוי ושמירת הגדרות.
- אפשרות לכבות את ההתראות מהגדרות התוסף.
- 100% מקומי, ללא רשת.

## מעקב אחר תוספים

ב־SDK 0.9.97 אין אירוע ציבורי ייעודי שמודיע איזה טאב תוסף הפך לפעיל. לכן Timeline משתמש ב־`reader.getCurrentState().openTabs` מתוך מנוע הרקע:

1. הסריקה הראשונה יוצרת baseline ולא נרשמת כהיסטוריה.
2. כל `toolId` חדש שמופיע לאחר מכן נרשם כאירוע.
3. מזהה שמתחיל ב־`builtin.` מסווג ככלי מובנה.
4. כל `toolId` אחר מסווג כתוסף.

כך פתיחת תוסף חדש נרשמת בלי להמציא API שלא קיים.

## התראות

התוסף משתמש ב־`notifications.showInApp` ובהרשאה `notifications.send`.
אלו הודעות Snack פנימיות של אוצריא, ולא התראות מערכת ההפעלה.

## תאימות 0.9.97

ה־manifest מצהיר:

`"minAppVersion": "0.9.97"`

ה־CI בודק שלא נוספו APIs ידועים שדורשים 0.9.98.

## אריזה

בכל push ל־`main`, GitHub Actions:
1. בודק manifest ותאימות 0.9.97.
2. בודק תחביר JavaScript.
3. אורז `timeline-plugin-<version>.otzplugin`.
4. בודק שהחבילה תקינה.
5. מעלה אותה כ־Artifact.

## פרטיות

כל הנתונים נשמרים ב־`plugin.storage` הפרטי של התוסף. אין שימוש ברשת.
