# Otzaria Timeline

תוסף ציר זמן מקומי לאוצריא.

## גרסה 0.12.0

גרסה זו ממשיכה את המעבר למראה והתנהגות של כלי Desktop מובנה באוצריא, ומוסיפה שיפורי אינטראקציה וביצועים.

### ממשק תואם אוצריא

- Rail צדדי צר עם אייקוני Fluent במצב Regular / Filled.
- הגדרות עם קטגוריות צדדיות בסגנון מסכי ההגדרות של אוצריא.
- Session-ים שטוחים יותר, עם קווי הפרדה במקום Cards גדולים.
- שדות חיפוש ובחירה משתמשים ב־Surface Containers של ערכת הנושא.
- כל צבעי Material 3 מגיעים מ־Theme של אוצריא.

### ציר הזמן

- הציר נשאר מסך ברירת המחדל.
- ריווח לפי פער הזמן בפועל.
- סימוני שעות על הציר.
- נקודות פעילות קטנות ועדינות.
- Tooltips עם שם ההפעלה, סיכום וטווח שעות.
- רינדור מדורג: לא כל ההיסטוריה נכנסת ל־DOM בבת אחת.
- כאשר מתקרבים לתחתית, נטענת אצווה נוספת של Sessions.

### חיפוש

- שדה חיפוש בסגנון אוצריא עם אייקון וניקוי מהיר.
- Debounce קצר לפני רינדור תוצאות.
- Ctrl+F מעביר למסך הציר וממקד את החיפוש.
- Esc מנקה חיפוש פעיל.

### מקלדת

- Ctrl+F — חיפוש בציר.
- Alt+1..6 — מעבר בין מסכי התוסף.
- J / K — מעבר בין Sessions בציר.
- Esc — סגירת תפריט הקשר / יציאה ממצב פוקוס / ניקוי חיפוש לפי ההקשר.

### תפריטי הקשר

קליק ימני על אירוע:
- פתיחה.
- הוספה/הסרה ממועדפים.
- פתיחת היסטוריית הספר או התוסף.
- העתקת פרטי האירוע.

קליק ימני על Session:
- שינוי שם.
- הערה.
- הצמדה.
- ייצוא.
- מחיקה.

### סנכרון חי

הממשק מרענן את נתוני הציר כאשר אוצריא מדווחת על:
- שינוי Workspace.
- פתיחת ספר.
- שינוי מיקום קריאה.
- ניווט.
- שינוי Theme.
- חזרה לתוסף.

### GitHub Release

ה־CI יוצר כעת Release אמיתי לכל גרסת Manifest:

- Tag בפורמט `vX.Y.Z`.
- Release notes אוטומטיים.
- קובץ `.otzplugin` כ־Release asset ישיר.
- אם ה־Release כבר קיים, ה־asset מתעדכן עם `--clobber`.
