# Otzaria Timeline

תוסף Timeline מתקדם ומקומי לאוצריא, בהשראת Windows Timeline.

## גרסה 0.7.0

התוסף תומך ב־**Otzaria 0.9.97 ומעלה** ואינו דורש שינוי בגוף התוכנה.

### Timeline חזותי
- ריווח בין Sessions לפי הזמן שעבר בפועל.
- Zoom בסגנון מפות עם כפתורי `+` / `−`.
- תצוגות יום / שבוע / חודש.
- צבע שונה לפי סוג הפעילות הדומיננטי: ספר, תוסף, כלי, Workspace או ניווט.
- כרטיס Session עם Summary חכם, Preview עשיר, Snapshot קרוב והערה אישית.

### Sessions
- שם ידני.
- הערה אישית.
- הצמדה וקיפול.
- שמירה כ־Workspace.
- מחיקה וייצוא של Session בודד.
- סימוני Snapshot לחיצים ישירות על הציר.

### Snapshots ושחזור
- Snapshot אוטומטי וידני.
- Snapshot Browser מלא.
- Preview לפני שחזור.
- שחזור חלקי: בחירת ספרים מתוך Snapshot.
- נקודת Undo אוטומטית לפני שחזור.
- עד 5 גיבויים פנימיים מתחלפים, עם שחזור דרך Diagnostics.

### חיפוש וסינון
חיפוש רגיל וגם אופרטורים:

- `book:"שם ספר"`
- `plugin:"שם תוסף"`
- `type:book`
- `date:2026-10-05`
- `session:"שם Session"`

בנוסף:
- מסננים שמורים.
- היום / אתמול / השבוע / הכול.
- מועדפים בלבד.
- סינון לפי תוסף מסוים.
- מיון חדש→ישן או ישן→חדש.

### ספרים ותוספים
- Timeline של תוסף מסוים.
- Timeline מלא של ספר מסוים.
- כל הביקורים והמיקומים שנרשמו בכל ספר.
- רשימת “מקומות אחרונים”.
- Top Books / Top Plugins.
- זיהוי תוסף שאינו מותקן עוד.
- מיפוי ידני מ־pluginId ישן ל־pluginId חדש.
- פתיחה מחדש של תוסף דרך `plugin.openOther`.
- שמות, גרסאות ואייקוני Fluent אמיתיים דרך `plugin.listInstalled`.

### Dashboard
- גרף פעילות ל־30 ימים.
- גרף 12 שבועות.
- גרף 12 חודשים.
- Heatmap שנתי.
- Top Books.
- Top Plugins.
- Recent Places.
- זמן ספרים משוער מול זמן תוספים/כלים משוער.

> זמן שימוש בתוסף הוא אומדן בלבד ב־0.9.97, משום שאין API ציבורי של active tool tab.

### Diagnostics / Health
- בדיקת הרשאות.
- מצב מעקב.
- גודל נתונים.

- אירוע אחרון.
- גיבויים פנימיים.
- תוספים חסרים.

### גיבוי וייצוא
- ייצוא מלא.
- ייצוא התצוגה המסוננת.

- ייצוא Session בודד.
- Import ומיזוג של קובץ Timeline קיים.

### קיצורי מקשים
ברירת המחדל:
- `Ctrl+Alt+T` — פתיחת Timeline.
- `Ctrl+Alt+S` — שמירת Snapshot.

המשתמש יכול לשנות אותם במסך קיצורי המקשים של אוצריא.

### אינטגרציה עם +
בהגדרות ניתן לבחור את Timeline כיעד של כפתור `+` דרך `plugin.setNewTabPage`.

האפשרות כבויה כברירת מחדל כדי לא להתנגש עם תוסף דף הבית.

### אינטגרציה עם Homepage
במאגר `Home-page-to-otzaria` נוסף כרטיס **“המשך עבודה”** כאשר Timeline מותקן.

הכרטיס פותח את Timeline עם:

`{ action: "continueLatest" }`

ו־Timeline מציג Preview של ה־Snapshot האחרון לפני השחזור.

### פרטיות
כל המידע נשמר מקומית בלבד. אין שימוש ברשת חיצונית.

## מגבלת SDK ידועה

ב־Otzaria 0.9.97 אין אירוע ציבורי של שינוי active tab לתוסף ואין `currentToolId`.

לכן:
- פתיחת/נוכחות תוספים נרשמת דרך `reader.getCurrentState().openTabs`.
- מעבר בין שני תוספים שכבר פתוחים אינו ניתן למדידה מדויקת.
- זמן תוספים הוא אומדן.

פתרון מלא לכך ידרוש שינוי API בגוף אוצריא, ולכן אינו חלק מהתוסף.

4. אורז את קבצי התוסף והאייקונים.
5. יוצר `timeline-plugin-0.7.0.otzplugin`.
6. בודק שהארכיון תקין.
7. מעלה אותו כ־Artifact.
