# Otzaria Timeline

תוסף Timeline מקומי לאוצריא, בהשראת Windows Timeline.

## גרסה 0.3.0

- ציר זמן לפי Sessions.
- תצוגות יום / שבוע / חודש.
- כרטיסי Session עשירים עם Preview של הפעילות האחרונה.
- Snapshot אוטומטי בערך כל 15 דקות ובמעבר שולחן עבודה.
- Snapshot ידני.
- גלריית Snapshots אחרונים.
- בחירת Snapshot מדויק מתוך Session.
- "המשך מהמקום שבו הפסקת".
- שחזור מבוקר של טאבי ספרים ומיקומי הקריאה.
- מעבר לשולחן העבודה המקורי אם הוא עדיין קיים.
- Heatmap של 35 הימים האחרונים.
- חיפושים אחרונים מתוך היסטוריית אוצריא.
- איחוד אירועי קריאה רציפים כדי למנוע הצפה.
- חיפוש וסינון לפי סוג פעילות וטווח זמן.
- השהיית תיעוד, ניקוי היסטוריה והגבלת מספר אירועים.
- 100% מקומי, ללא רשת.

## איך השחזור עובד

ה-SDK מאפשר לקרוא את הטאבים הפתוחים, לשחזר ספרים ומיקומים ולעבור בין שולחנות עבודה. בזמן שחזור:

1. התוסף מבקש אישור.
2. אם שולחן העבודה המקורי עדיין קיים, התוסף עובר אליו.
3. נסגרים רק טאבי ספרים שניתנים לשחזור.
4. הספרים נפתחים מחדש במיקומים שנשמרו.
5. טאבי כלים ותוספים נשארים ללא שינוי.

## אריזה

בכל push לענף `main`, GitHub Actions:

1. בודק את `manifest.json`.
2. בודק תחביר של `app.js` ו-`background.js`.
3. אורז את קבצי התוסף.
4. יוצר `dist/timeline-plugin.otzplugin`.
5. מעלה אותו כ-Artifact בשם `timeline-plugin`.

קובץ `.otzplugin` הוא חבילת התוסף להתקנה באוצריא.

## מגבלת שחזור

ה-SDK אינו חושף מספיק מידע כדי לשחזר היסטורית כל סוג טאב של כלי, תוסף או חיפוש. לכן התוסף אינו מנסה לשחזר מידע שאין לו דרך לבנות מחדש במדויק.

## פרטיות

הנתונים נשמרים רק ב-`plugin.storage` הפרטי של התוסף ואין שימוש ברשת.
