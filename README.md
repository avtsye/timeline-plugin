# Otzaria Timeline

תוסף ציר זמן מקומי לאוצריא.

## גרסה 0.10.0

גרסה זו עוברת למבנה ממשק מלא התואם למדריך העיצוב הרשמי של אוצריא ול־Material Design 3.

### מבנה חדש

בכניסה לתוסף מוצג **מסך הציר בלבד**.

שאר האזורים עברו למסכים נפרדים בסרגל צד:
- ציר הזמן
- סקירה
- שחזור
- פעילות
- אבחון
- הגדרות

### התאמה מלאה לאוצריא

הממשק משתמש ב־Application Shell לפי ה־Design Guide הרשמי:

- פס עליון קבוע בגובה 56px.
- במסך צר הפס יורד ל־44px.
- רקע הפס הוא `surfaceContainerHigh`.
- התוכן עצמו גולל בנפרד מהפס העליון.
- סרגל הצד משתמש ב־`secondaryContainer` עבור היעד הפעיל.
- אין צבעי ממשק קשיחים עבור המצבים הפעילים.
- כל צבעי Material 3 מגיעים מאובייקט ה־theme של אוצריא.
- תמיכה מלאה במצב בהיר/כהה.
- `uiFontFamily` משמש רק לממשק.
- `fontFamily` נשמר בנפרד עבור טקסט קריאה.
- כל הרכיבים משתמשים ברדיוסים ובשכבות Surface לפי M3.
- אייקוני סרגל הצד מגיעים ממפת Fluent הרשמית שכבר ארוזה בתוסף.

### מסך ציר הזמן

מסך ברירת המחדל כולל רק:
- שורת חיפוש וסינון.
- Zoom.
- יום / שבוע / חודש.
- מצב פוקוס.
- הציר עצמו.

סטטיסטיקות, Heatmap, חיפושים אחרונים ונקודות שחזור אינם מוצגים סביב הציר.

### מסך סקירה

כולל:
- המשך עבודה.
- סטטיסטיקות.
- 35 הימים האחרונים.
- חיפושים אחרונים.
- ניווט מהיר ומסננים שמורים.

### מסך שחזור

כולל:
- שמירת נקודת שחזור.
- נקודות שחזור אחרונות.
- דפדפן נקודות שחזור.
- ייצוא / ייבוא.
- ארכיון מתומצת.

### מסך פעילות

גישה ללוח הפעילות:
- גרפים יומיים.
- שבועיים.
- חודשיים.
- Heatmap שנתי.
- Top Books / Top Plugins.
- Recent Places.

### מסך אבחון

כולל:
- מצב מעקב.
- הרשאות.
- בריאות הנתונים.
- גיבויים.
- תוספים חסרים.
- אבחון מפורט.

### הגדרות

ההגדרות הן עכשיו **מסך מלא** בתוך הניווט ולא חלון Modal.

הן מחולקות לטאבים:
- כללי
- מעקב
- גיבוי ושחזור
- אינטגרציות
- תחזוקה ומשוב

### בדיקות Runtime

ה־CI ממשיך לבדוק:
- תחביר JavaScript.
- התאמת כל מזהי ה־DOM לקוד.
- פונקציות Runtime קריטיות.
- מניעת התנגשות עם מנגנון התרגום.
- APIs ידועים שאינם תואמים ל־Otzaria 0.9.97.
- תקינות חבילת `.otzplugin`.
