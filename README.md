# Otzaria Timeline

תוסף ציר זמן מקומי לאוצריא, בהשראת Windows Timeline.

## מה קיים בגרסה 0.1.0
- איסוף פעילות ברקע מהפעלת אוצריא.
- רישום פתיחת ספרים, ניווט, החלפת סביבת עבודה והפעלת התוכנה.
- חלוקה אוטומטית לסשנים (פער של 30 דקות יוצר סשן חדש).
- תצוגת Timeline לפי ימים ושעות.
- חיפוש וסינון לפי סוג פעילות וטווח זמן.
- פתיחה מחדש של אירועי ספר.
- השהיית תיעוד, ניקוי היסטוריה והגבלת מספר האירועים.
- אחסון מקומי בלבד; אין שימוש ברשת.
- התאמה לערכת הנושא של אוצריא.

## מבנה
- `index.html` — ממשק המשתמש.
- `app.js` — הצגה, חיפוש, סינון ושחזור.
- `background.html` / `background.js` — איסוף אירועים ברקע.
- `manifest.json` — הרשאות ותרומות לאוצריא.

## המשך מתוכנן
- Snapshots של מצב עבודה מלא.
- שחזור קבוצת טאבים/Session.
- חיפושים קודמים בציר הזמן.
- Heatmap שבועי/חודשי.
- איחוד אירועים רציפים לאותה פעילות.
- ייצוא/ייבוא וגיבוי מקומי.

## פרטיות
כל המידע נשמר באחסון הפרטי של התוסף בתוך אוצריא ואינו נשלח לשום שרת.
