# Otzaria Timeline

תוסף Timeline מקומי לאוצריא, בהשראת Windows Timeline.

## גרסה 0.6.0

הגרסה הנוכחית נשארת תואמת ל־**Otzaria 0.9.97 ומעלה** ואינה דורשת שינוי בגוף התוכנה.

### ציר הזמן
- תצוגת יום כציר חזותי עם קו, נקודות זמן וכרטיסי Session.
- תצוגות שבוע וחודש.
- קיצורי היום / אתמול / השבוע / הכול.
- לחיצה על יום ב־Heatmap מסננת לאותו יום.
- חיפוש לפי ספר, תוסף, Workspace או טקסט חופשי.
- סינון לפי סוג פעילות ולפי תוסף מסוים.
- מיון חדש→ישן / ישן→חדש.
- מצב קומפקטי.

### Sessions
- כותרת חכמה אוטומטית.
- שם ידני.
- הצמדה.
- קיפול/פתיחה.
- מחיקת Session בודד.
- שמירת Session כ־Workspace חדש.
- שחזור Snapshot קרוב או Snapshot מדויק.
- סימוני Snapshot לחיצים ישירות על ציר הזמן.

### ספרים, תוספים וכלים
- מעקב ספרים ומיקומי קריאה.
- מעקב פתיחת תוספים וכלים דרך `reader.getCurrentState().openTabs`.
- מצב מעקב שמציג אם הרשאות הרקע אושרו.
- `plugin.listInstalled` לשמות, גרסאות ומצב תוסף.
- אייקוני Fluent אמיתיים לפי `toolTabIconName`.
- “אחרון בכל תוסף”.
- פתיחה מחדש של תוסף דרך `plugin.openOther`.
- לכלי מובנה אין ב־0.9.97 API כללי לפתיחה מחדש, ולכן מוצגת הודעה במקום פעולה שגויה.

### מועדפים וסטטיסטיקות
- סימון אירוע כמועדף.
- מצב “מועדפים בלבד”.
- מספר ספרים ותוספים שנראו במסנן.
- זמן ספרים משוער.
- זמן תוספים/כלים משוער.

> זמן הפעילות הוא אומדן לפי מרווחים בין אירועים, עם cap כדי לא לספור זמן idle ארוך. בלי API של active-tab אין דרך למדוד זמן תוסף מדויק ב־0.9.97.

### גיבוי
- ייצוא מלא לקובץ JSON דרך API הקבצים של אוצריא.
- ייבוא ומיזוג של Timeline קיים.
- הייצוא כולל Events, Snapshots, הגדרות, שמות Sessions, Pins, Collapsed ומועדפים.

### התראות
- התראות פנימיות של אוצריא על Snapshot, שחזור, ניקוי, שמירת הגדרות ועוד.
- ניתן לכבות אותן בהגדרות.

## מגבלת SDK חשובה

ב־Otzaria 0.9.97 אין אירוע ציבורי של “הטאב הפעיל השתנה לתוסף X” ואין `currentToolId`.
לכן Timeline מזהה פתיחה/נוכחות של תוספים דרך רשימת הטאבים הפתוחים, אך אינו יכול למדוד מעבר מדויק בין שני תוספים שכבר פתוחים. תיקון מלא של זה ידרוש API חדש בגוף אוצריא, ולכן אינו חלק מהגרסה הזו.

## אריזה

בכל push ל־`main`, GitHub Actions:
1. בודק את manifest ואת `minAppVersion: 0.9.97`.
2. בודק תחביר JavaScript.
3. בודק שלא נוספו APIs ידועים של 0.9.98.
4. אורז גם את מפת אייקוני Fluent.
5. יוצר `timeline-plugin-0.6.0.otzplugin`.
6. בודק שהארכיון תקין.
7. מעלה אותו כ־Artifact.

## פרטיות

כל הנתונים נשמרים מקומית ב־`plugin.storage` ובקבצים שהמשתמש בוחר לייצא אליהם. אין שימוש ברשת חיצונית.
