# Otzaria Timeline

תוסף ציר זמן מקומי לאוצריא.

## גרסה 0.9.0

תומך ב־Otzaria 0.9.97 ומעלה, ללא שינוי בגוף אוצריא.

### תיקון חשוב

ב־0.8.0 הייתה התנגשות שם בין פונקציית התרגום `t()` לפרמטר בפונקציית כותרת היום. בזמן רינדור של תצוגת יום נזרקה שגיאת Runtime ולכן הציר עצמו לא הוצג.

ב־0.9.0 ההתנגשות תוקנה, ונוספה בדיקת Runtime ייעודית ל־CI שבודקת גם:
- התאמת מזהי DOM בין `app.js` ל־`index.html`.
- פונקציות Runtime קריטיות.
- התנגשות שמות עם פונקציית התרגום.
- הפניות ישנות לרכיבים שכבר הוסרו.

### מסך פתיחה נקי

במסך הראשי נשארים במרכז:
- המשך עבודה.
- ניווט וחיפוש.
- ציר הזמן עצמו.

סטטיסטיקות, 35 הימים האחרונים, נקודות שחזור אחרונות וחיפושים אחרונים עברו לאזורים מתקפלים.

### מצב פוקוס

כפתור מצב פוקוס מסתיר את כל הפאנלים המשניים ומשאיר את ציר הזמן עצמו.

### תפריט פעולות להפעלה

במקום שורת כפתורים ארוכה, לכל הפעלה יש תפריט `⋯` עם:
- שם.
- הערה.
- הצמדה.
- קיפול.
- שמירה כסביבת עבודה.
- ייצוא.
- בחירת נקודת שחזור.
- מחיקה.

### Tooltips

מעבר עכבר על נקודת זמן מציג Tooltip עם:
- שם ההפעלה.
- סיכום פעילות.
- טווח שעות.

### הגדרות בטאבים

חלון ההגדרות מחולק ל:
- כללי.
- מעקב.
- גיבוי ושחזור.
- אינטגרציות.
- תחזוקה ומשוב.

### בחירת מה לתעד

ניתן להפעיל או לכבות בנפרד:
- פתיחת ספרים.
- מיקומי קריאה.
- תוספים.
- כלים מובנים.
- סביבות עבודה.

### מצב פרטיות

ניתן:
- להשהות לשעה.
- להשהות עד ההפעלה מחדש של אוצריא.
- לחדש מייד.

### ארכיון מתומצת

בנוסף לחמשת הגיבויים המלאים, הגיבוי האוטומטי יוצר `backups/archive-summary.json`.

הארכיון שומר סיכום קטן לפי יום:
- מספר אירועים.
- מספר הפעלות.
- התפלגות סוגי פעילות.
- ספרים מובילים.
- תוספים מובילים.

אפשר לפתוח אותו מתוך הגדרות > גיבוי ושחזור.

### משוב

בהגדרות > תחזוקה ומשוב ניתן לשלוח:
- דיווח על תקלה.
- משוב / הצעה.

השליחה משתמשת ב־`feedback.report` הרשמי של אוצריא. אוצריא מציגה למשתמש דיאלוג אישור לפני השליחה ויכולה לשמור את הדיווח בתור מקומי אם אין חיבור.

### תמיכה מלאה בערכת העיצוב של אוצריא

התוסף מאזין ל־`theme.changed` ומשתמש בכל תפקידי Material 3 המרכזיים שאוצריא מספקת:
- Primary / Secondary / Tertiary.
- כל שכבות Surface Container.
- Error / Error Container.
- Outline / Outline Variant.
- Inverse Surface / Inverse Primary.
- Shadow / Scrim / Surface Tint.
- מצב Light / Dark.
- `uiFontFamily` לממשק.
- גופן הקריאה נשמר בנפרד בהתאם ל־Design Guide של אוצריא.

### שפה
