# Otzaria Timeline

תוסף ציר זמן מקומי ומתקדם לאוצריא, בהשראת Windows Timeline.

## גרסה 0.8.0

התוסף תומך ב־**Otzaria 0.9.97 ומעלה** ואינו דורש שינוי בגוף אוצריא.

### מה חדש ב־0.8.0

- הוסר האזור **“אחרון בכל תוסף”** מהמסך הראשי.
- נוספה תמיכה מלאה בעברית ובאנגלית.
- ברירת המחדל היא התאמה אוטומטית לשפת הממשק של אוצריא.
- ניתן לבחור ידנית עברית / English / אוטומטי.
- במצב אנגלית הממשק עובר גם ל־LTR.
- תאריכים, חלונות, הודעות, אבחון, שחזור, קיצורי מקשים והודעות רקע מתורגמים בהתאם לשפה.
- הממשק עוצב מחדש כך שיישען על צבעי Material 3, גופני הממשק וערכת הנושא של אוצריא.
- הוסרו גרדיאנטים ועיצוב שאינו תואם לאוצריא.
- שורת הכותרת נוקתה לחלוטין.
- פעולות כגון שמירת נקודת שחזור, דפדפן נקודות שחזור, לוח פעילות, אבחון, ייצוא, ייבוא והשהיית מעקב עברו לחלון **הגדרות**.
- ההגדרות נפתחות מכפתור גלגל שיניים צף קטן ואינן תופסות מקום בשורת הכותרת.

### ציר הזמן

- ריווח בין הפעלות לפי הזמן שעבר בפועל.
- Zoom עם כפתורי + / −.
- תצוגות יום / שבוע / חודש.
- צבע לפי סוג הפעילות הדומיננטי.
- כרטיס הפעלה עם Summary, Preview, הערות ונקודת שחזור קרובה.
- חיפוש מתקדם:
  - `book:`
  - `plugin:`
  - `type:`
  - `date:`
  - `session:`
- מסננים שמורים.
- היום / אתמול / השבוע / הכול.
- מועדפים.
- Timeline נפרד לספר או לתוסף.
- כל הביקורים והמיקומים שנרשמו בספר.
- Dashboard עם גרפים יומיים, שבועיים וחודשיים.
- Heatmap שנתי.
- Top Books / Top Plugins.
- Recent Places.

### נקודות שחזור וגיבוי

- נקודות שחזור אוטומטיות וידניות.
- דפדפן נקודות שחזור.
- Preview לפני שחזור.
- שחזור חלקי של ספרים נבחרים.
- נקודת Undo אוטומטית לפני שחזור.
- עד 5 גיבויים פנימיים מתחלפים.
- שחזור גיבויים מתוך מסך האבחון.
- ייצוא מלא, ייצוא מסונן, ייצוא של היום וייצוא הפעלה בודדת.
- Import ומיזוג של קובץ Timeline קיים.

### תוספים

- מעקב אחר פתיחת תוספים וכלים.
- שמות וגרסאות מתוך `plugin.listInstalled`.
- פתיחה מחדש של תוסף דרך `plugin.openOther`.
- זיהוי תוסף חסר.
- מיפוי pluginId ישן לחדש דרך מסך האבחון.

> ב־Otzaria 0.9.97 אין API ציבורי שמחזיר את הטאב הפעיל של תוסף. לכן זמן שימוש בתוספים הוא אומדן, ומעבר בין שני תוספים שכבר פתוחים אינו ניתן למדידה מדויקת ללא שינוי בגוף אוצריא.

### קיצורי מקשים

קיצורי ברירת המחדל:
- `Ctrl+Alt+T` — פתיחת ציר הזמן.
- `Ctrl+Alt+S` — שמירת נקודת שחזור.

שמות הקיצורים נרשמים לפי שפת הממשק וניתנים לשינוי במסך הקיצורים של אוצריא.

### אינטגרציות

- אפשרות לבחור את Timeline כיעד כפתור `+`.
- האפשרות כבויה כברירת מחדל.
- אינטגרציה עם `Home-page-to-otzaria` עבור “המשך עבודה”.

### פרטיות

כל הנתונים נשמרים מקומית בלבד. אין שימוש ברשת חיצונית.

## אריזה

בכל push ל־`main`, GitHub Actions:
1. בודק את `manifest.json`.
2. בודק תאימות ל־0.9.97.
3. בודק תחביר JavaScript.
4. אורז את קבצי התוסף.
5. יוצר `timeline-plugin-0.8.0.otzplugin`.
6. בודק שהארכיון תקין.
7. מעלה אותו כ־Artifact.
